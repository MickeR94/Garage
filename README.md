# Garage Program
This is the first iteration of a Garage-program for the Lexicon labor training course in C#/.NET fullstack development.
The program serves as an exercise in Object-Oriented Programming.

## Functionality
This program is written in C# and uses multiple classes and methods.
* The program allows the user to create a new garage with a specified number of spots.
* The user can choose a vehicle type to add to the garage. All vehicles inherits from the Vehicle class. Depending on the choice of vehicle to park, the user will be prompted to enter specific properties for that vehicle
* The user can remove a vehicle
* The user can list all vehicles in the garage, as well as seeing the the number of each vehicle type

## Future work
The program needs proper error handling. It also needs thorough testing to see if each possible choice results in the desired outcome.
There are also requirements from the specification that are not yet implemented. 
For example, allow the user to populate the garage immediately as it is created, proper feedback to user when something goes wrong/right, and to not allow for the same registration number being added twice.

Adding persistance and frontend would also be beneficial.
